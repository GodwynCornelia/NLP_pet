из 3080. Сверены исходные CSV, очистка 7+4 строк, split 6994/1499/1499, 77 классов

веса и полный машинный журнал остаются локальными.

## Чистый контейнерный прогон

Подтверждён один полный ML-прогон Linux/amd64 в отдельной копии исходников, без
предсуществующих `.venv`, данных, весов, outputs и кешей проекта. Зависимости
установлены по lock; CSV и 12 файлов encoder загружены программно по закреплённым
версиям без токена. Ручного копирования ресурсов не было.

Bootstrap выполнил обучение шести прежних конфигураций и прежнее правило выбора
по validation_model. Policy выбрана на validation_policy; test оценён после фиксации.

Score/threshold различаются; исходная модель не заменена. Бинарного совпадения
повторно обученных файлов на разных ОС не требуется. Это воспроизведение фиксированного
протокола **на уже известном test**, а не новая независимая оценка качества.

Фактически прошли build, prepare, up, UI→API HTTP, health/ready/predict/batch,
ошибки строк CSV и безопасный экспорт, Streamlit AppTest, verify-artifacts, инференс
при `--network none` для нового и исходного run. После restart API/UI повторный smoke
прошёл, артефакты не изменились. Проверка из UI-контейнера запрещала внешние sockets,
сохраняя внутреннюю связь; запрет сокетов в проверяющем процессе не является
сетевой политикой всех контейнеров.

## Ручная проверка и границы доказательств

По скриншотам ручного запуска подтверждены три вкладки, два английских обращения,
top-3/route/retrieval, CSV-предпросмотр и результат с двумя item errors, метрики и
таблицы путаниц. Скачанный файл и визуальное предупреждение об усечении не показаны.
Экспорт и truncation проверены автоматически. Скриншоты в репозиторий не включены.
[Чек-лист](manual_ui_checklist.md). Студенческий самостоятельный разбор ошибок не заявлен.

Публичные JSON/CSV сформированы `scripts/write_run_summary.py` и
`scripts/write_finishing_summary.py` из локальных первичных файлов. Имена источников,
исходный run, SHA-256 и хеши публичных проекций записаны в
[provenance.json](../reports/public/provenance.json) и reproducibility.json.
Исходные полные receipts не распространяются: они содержат локальные пути и служебные
данные. Публичные копии используют список разрешённых полей.
Публичные JSON/CSV записываются как UTF-8 с LF; `.gitattributes` сохраняет единые
окончания строк, чтобы SHA-256 из provenance не менялись между checkout на разных ОС.
Повторный запуск генераторов не изменяет README, карточки, веса или первичные отчёты.
Для генерации требуется завершённый локальный run; для finishing — сохранённые receipts.
Эти receipts не требуются для bootstrap, API, UI или тестов обычной чистой установки.
